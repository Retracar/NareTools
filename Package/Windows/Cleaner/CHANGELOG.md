# 更新记录

## 1.3.0

### 截图目录与识别

- 在设置中点击「检测目录」，可从 Windows 图片、视频和捕获位置查找截图目录，包括部分游戏和录制工具使用的目录，以及名称带 Screenshot、截图等字样的文件夹。勾选需要管理的位置后保存设置。
- 手动添加目录时可按住 Ctrl 一次选择多个文件夹。
- 扩大了简繁中文和游戏截图文件名的识别范围，包括「截图」「屏幕截图」「螢幕擷取」等命名。使用自定义文件名时，可在对应目录启用「包含所有支持的图片」。

### 浏览与预览

- 新增小图视图和列表缩略图。清理预览的列表未选中截图时，把鼠标停在某一行即可在右侧查看图片。
- 在最近截图和清理预览中，可右键使用系统默认图片查看器打开截图。宽窗口会自动增加列数，利用更多横向空间。
- 最近截图的多选操作移至底部，选择图片时浏览区域保持原位。

### 清理选中的截图

- 在「清理预览」勾选截图后，可以选择「清理选中截图」，也可以按设定的时间范围清理匹配项。
- 多选时，右侧显示最多四张叠放缩略图，并列出选中数量、总大小和涉及的目录数。
- 叠放缩略图按整组居中，新选中的图片会从上方滑入后层。
- 清理的文件可从 Windows 回收站还原，长期保留的截图会排除在清理范围之外。

### 自动清理计划

- 清理周期统一为每 7 天、每 14 天、每 30 天或自定义。选择「自定义」时可设置天、周或月。每次检查只清理超过该周期的截图。
- 未开启自动清理时，可在概览选择 7、14 或 30 天，再点「确定」。首次清理在所选周期后执行，沿用设置中的执行时间。「自定义」会打开设置页。
- 已启用的旧计划继续使用原规则。修改周期并保存后，新规则生效。关闭自动清理并保存后，首页显示「未设置」。
- 清理预览可独立选择一次性的手动清理范围。
- 开启自动清理后，概览以大号数字显示倒计时，并列出计划执行时间。
- 新建或重新开启计划时，起始日期默认为今天。使用默认起算方式时，首次执行前修改周期，倒计时和 Windows 计划任务会随新周期重新计算。

### 设置与状态信息

- 「设置 → 外观 → 截图状态信息栏」可选「简约」或「独立」。默认的「简约」在侧栏「最近截图」旁显示总数，更新时间在概览的总数卡片里。「独立」在侧栏底部集中显示数量、扫描状态和更新时间。
- 修改设置后才显示「保存设置」。切换页面或关闭窗口时会列出未保存的更改，可保存、放弃或继续编辑。
- 可从「设置 → 应用数据」直接打开数据目录。

### 外观与动效

- 优化了深色模式，修复部分按钮和卡片悬停时短暂闪浅色的问题，减轻侧栏选中项的字重。
- 侧栏采用微软 Fluent 彩色图标，选中项使用半透明灰底。浅色卡片保留轻微的底色变化，下拉菜单使用亚克力效果。
- 优化了菜单在窗口边缘的弹出位置，以及选择栏和右侧预览窗格显示、隐藏时的过渡动效。
- 概览清理卡片采用更紧凑的布局，叠放最多三张最近截图。开启自动清理后，堆叠改为显示待清理截图。没有可预览的截图时显示扫帚，进入概览或将鼠标移到扫帚上时会轻扫一次。

## 1.2.0

- 支持 Windows 10 22H2（构建 19045）及更新版本的 x64 系统。
- 扩展截图目录检测和文件命名识别。支持多选目录和单独放宽目录命名规则。
- 增加小图、列表缩略图、悬停预览和选中清理。多选时可以查看图片叠放和合计大小。
- 改进菜单定位、深色状态、宽窗口布局和面板过渡。

## 1.1.1

- 覆盖升级后首次打开会显示一页更新内容，确认后进入主界面，沿用原有设置。
- 卸载后重装会重新进入设置引导。选择保留的数据会用于预填截图目录和保留期限。

## 1.1.0

- 安装时自动检测 Windows 截图目录，支持在独立步骤中确认或添加其他目录。
- 新增简体中文、英语、繁体中文、韩语和日语，默认跟随系统。
- 优化安装与首次设置布局、加载页和卡片动效。
- 修复截图数量较少时，缩略图可能需要再次操作才显示的问题。
- 改进清理期间的退出处理，安全停止后再关闭程序。

## 1.0.1

- 优化部分性能与资源占用。
- 改进截图浏览与页面切换体验。
- 优化安装、升级及卸载流程。
- 完善卸载选项，支持保留或清除应用数据。
- 修复部分已知问题，提升使用稳定性。

## 1.0.0

首次正式发布 Windows Cleaner。

- 最近截图与清理预览分开，支持列表、中图、大图及显示方式记忆。
- 截图复制、分享、重命名、文件夹定位和多选删除。
- 多目录管理、长期保留、7／14／30 天自动保留期限。
- 手动选择几天、几周或几个月前的截图，一次清理匹配项。
- 每 N 天／周／月执行，可设置起始日期与时间；无需后台常驻，不唤醒电脑。
- 清理进度、停止操作及部分完成记录；文件移入 Windows 回收站。
- Windows 11 云母与亚克力，绿色、青色和壁纸取色，统一的原生控件与导航。
- 分步安装与首次引导，可选安装位置及快捷方式。
- 优化批量清理、图片加载和页面响应。
