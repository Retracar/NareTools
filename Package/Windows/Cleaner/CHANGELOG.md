# 更新记录

## 1.0.0

首次正式发布 Windows Cleaner。

- 最近截图与清理预览分开，支持列表、中图、大图及显示方式记忆。
- 截图复制、分享、重命名、文件夹定位和多选删除。
- 多目录管理、长期保留、7／14／30 天自动保留期限。
- 手动选择几天、几周或几个月前的截图，一次清理匹配项。
- 每 N 天／周／月执行，可设置起始日期与时间；无需后台常驻，不唤醒电脑。
- 清理进度、停止操作及部分完成记录；文件移入 Windows 回收站。
- Windows 11 云母与亚克力，绿色、青色和壁纸取色，统一的原生控件与导航。
- 分步安装与首次引导，可选安装位置及快捷方式。
- 批量回收、图片缓存和界面响应优化；正式发布前核对删除范围、恢复结果与安装生命周期。
