# 更新记录

## 1.0.1

- 缩小完整离线安装包：使用官方 WinUI 组件包、独立安装界面工程及统一压缩，移除未使用的 AI、ML、Search、Widgets 和旧图形实验依赖。
- 相同运行库在安装临时目录复用，不支持硬链接时自动复制；最终安装文件内容保持完整，退出安装器后清理临时文件。
- 新增统一风格的卸载确认窗口，可保留或清除设置、保护名单和清理记录，默认保留。截图及未知的用户文件不会随卸载删除。
- 升级和卸载前正常关闭应用，安全停止进行中的清理，避免运行库被占用后残留；损坏设置或不完整安装也有恢复处理。
- 升级移除内容与旧版清单完全一致的多余依赖，保留用户改动的文件；卸载后重装不会自行重新开启清理。
- 修复快速浏览图片时的布局重入问题，以及独立卸载窗口初始化滚动组件时的异常。
- 加入普通运行模式的 CPU、私有内存、空闲读写与连续切页稳定性检查，保留有容量上限的图片缓存。

## 1.0.0

首次正式发布 Windows Cleaner。

- 最近截图与清理预览分开，支持列表、中图、大图及显示方式记忆。
- 截图复制、分享、重命名、文件夹定位和多选删除。
- 多目录管理、长期保留、7／14／30 天自动保留期限。
- 手动选择几天、几周或几个月前的截图，一次清理匹配项。
- 每 N 天／周／月执行，可设置起始日期与时间；无需后台常驻，不唤醒电脑。
- 清理进度、停止操作及部分完成记录；文件移入 Windows 回收站。
- Windows 11 云母与亚克力，绿色、青色和壁纸取色，统一的原生控件与导航。
- 分步安装与首次引导，可选安装位置及快捷方式。
- 批量回收、图片缓存和界面响应优化；正式发布前核对删除范围、恢复结果与安装生命周期。
