# 更新记录

## 1.1.1

- 覆盖升级后首次打开会显示一页更新内容，确认后进入主界面，沿用原有设置。
- 卸载后重装会重新进入设置引导。选择保留的数据会用于预填截图目录和保留期限。

## 1.1.0

- 安装时自动检测 Windows 截图目录，支持在独立步骤中确认或添加其他目录。
- 新增简体中文、英语、繁体中文、韩语和日语，默认跟随系统。
- 优化安装与首次设置布局、加载页和卡片动效。
- 修复截图数量较少时，缩略图可能需要再次操作才显示的问题。
- 改进清理期间的退出处理，安全停止后再关闭程序。

## 1.0.1

- 优化部分性能与资源占用。
- 改进截图浏览与页面切换体验。
- 优化安装、升级及卸载流程。
- 完善卸载选项，支持保留或清除应用数据。
- 修复部分已知问题，提升使用稳定性。

## 1.0.0

首次正式发布 Windows Cleaner。

- 最近截图与清理预览分开，支持列表、中图、大图及显示方式记忆。
- 截图复制、分享、重命名、文件夹定位和多选删除。
- 多目录管理、长期保留、7／14／30 天自动保留期限。
- 手动选择几天、几周或几个月前的截图，一次清理匹配项。
- 每 N 天／周／月执行，可设置起始日期与时间；无需后台常驻，不唤醒电脑。
- 清理进度、停止操作及部分完成记录；文件移入 Windows 回收站。
- Windows 11 云母与亚克力，绿色、青色和壁纸取色，统一的原生控件与导航。
- 分步安装与首次引导，可选安装位置及快捷方式。
- 优化批量清理、图片加载和页面响应。
