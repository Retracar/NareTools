# NareTools Cleaner 使用说明

本文对应 1.2.0。[下载安装包](https://github.com/Retracar/NareTools/releases/latest)。

## 安装与首次使用

安装包为 `NareTools-1.2.0-Setup-x64.exe`，适用于 Windows 10 22H2（构建 19045）及更新版本的 x64 系统，无需另装 .NET。安装包尚未配置代码签名。

可安装至具有写入权限的其他本地目录，包括 D 盘。桌面快捷方式、开始菜单入口分别设置；截图管理目录放在单独步骤。安装目录与截图目录相互独立。

首次安装或卸载后重装时，启动会进入设置引导，确认截图目录和 7／14／30 天保留期限。重装时可沿用保留的设置，自动清理保持关闭。覆盖升级后首次打开会显示一页更新内容，点击「继续」进入主界面。日常启动直接进入主界面。

## 最近截图

「最近截图」用于浏览和日常文件操作，与按期限清理的页面分开。

- 可切换列表、小图、中图和大图，重新打开后沿用上次选择。列表也显示缩略图。
- 卡片的「复制」复制图片；「更多」提供打开、复制路径、文件夹定位、长期保留、重命名和删除。
- 多选后可复制文件、分享或删除所选项。删除需要确认，长期保留项排除。
- 选择操作显示在页面底部。右键图片可用系统默认图片查看器打开。
- 重命名不覆盖同名文件，不接受系统保留名称、路径或非法字符；长期保留状态随新路径更新。

分享使用 Windows 系统分享面板，可用目标由系统和已安装应用决定。

## 按期限清理

概览设置自动保留期限，默认 30 天，与执行频率独立。在「清理预览」可选择几天、几周、几个月前的截图，月份按实际日历计算。使用文件最后修改时间，文件名日期不是清理依据。

「清理匹配截图」按当前日期范围和筛选条件处理。「清理选中截图」只处理勾选的文件，范围独立于日期条件。多选时，预览窗格显示最多四张缩略图、总大小、目录数及长期保留数量。列表没有选择时，鼠标停在某行即可预览。

搜索与状态筛选共同决定当前预览中的匹配范围。确认窗口显示数量、大小、目录数和截止时间；确认期间不扩大文件快照或重新计算截止时间。

原生进度条显示处理数量和已回收数量。「停止」会请求停止后续文件，正在进行的系统操作完成或返回后才结束；已完成项保留在回收站。错误或取消均保留部分完成记录。

文件使用 Windows 批量回收接口。每个文件实际回收前重验目录、保护名单、属性、大小和修改时间。排队前变化的文件跳过；已排队文件或规则变化时停止。进度更新合并处理，空闲时不持续刷新。

长期保留不修改文件内容。保护名单记录完整路径，保护变更与清理不能同时执行；繁忙时请稍后重试。

## 目录与识别标准

「设置 → 截图目录」最多添加 32 个专用目录，共用自动保留期限和周期。添加目录时可按 Ctrl 多选。「检测目录」会在系统截图、图片和视频等位置附近查找，勾选需要的目录后保存。移除管理目录不删除文件。

仅扫描各目录第一层，不递归。父子目录分别扫描其第一层；相同路径按 Windows 不区分大小写的规则去重。

支持 PNG、JPG、JPEG、WEBP、BMP，默认识别常见系统和游戏截图命名。若目录有图片却显示 0 张，可查看目录下方的排除数量。若确认是专用截图目录，可勾选「包含所有支持的图片」再保存。

隐藏、系统和链接文件排除。不支持磁盘根目录、个人资料根目录、图片根目录或网络目录。任一目录失效时暂停本轮。不要同时用其他工具修改正在清理的目录；核验与系统操作之间仍存在短暂间隔。

## 自动清理

在「清理计划」开启自动清理，设置每 N 天／周／月、起始日期和时间后保存。时间使用 Windows 原生选择器。

周期按起始日期计算：从 1 月 31 日开始每月执行，2 月在最后一天，3 月仍在 31 日。错过多次时合并补做一次，周期仍沿用起始日期；未来起始日期不会提前执行。

计划使用 Windows 任务计划程序，登录且插电时运行，不唤醒电脑，无需后台常驻。退出应用不会取消计划，关闭计划须在设置中关闭并保存。

手动移动解压版前，先关闭自动清理，再从新位置启动并重新开启，避免任务仍引用旧路径。安装版通过安装程序更改位置，程序文件与截图保存位置相互独立。

## 外观与图片

默认云母、Nare 绿色及跟随 Windows 深浅主题，可选择亚克力、纯色、默认青色或壁纸取色。系统透明效果、对比度或节能策略可能使材质回退。

二级页面点击面包屑上级名称返回。正文使用 WinUI 官方进入转场并遵循系统动画设置。实际刷新率由显示器、系统与负载共同决定。

图片按可见区域异步加载，共享进行中的请求，最多两个并发解码。缓存最多 64 张、24 MiB，用于返回页面及滚动复用，不持久锁定原文件。解码失败时仍可用默认应用打开。

## 数据与恢复

配置、保护名单和最近 100 条清理记录保存在 `%LOCALAPPDATA%\NareTools-Cleaner`，与安装目录独立。工具不上传截图内容。

所有清理和删除使用 Windows 回收站，没有永久删除或清空回收站按钮。回收站仍占用磁盘，清空后才释放空间；Windows 存储感知可能按系统设置自动清理回收站。

在 Windows“设置 → 应用 → 已安装的应用”中卸载 NareTools。确认窗口默认保留设置、保护名单和清理记录，可勾选清除应用数据。卸载移除程序、快捷方式和清理计划，截图及其所在目录始终保留。安装目录内未知的用户文件也会保留。

应用正在执行文件操作时，卸载会先请求安全停止并等待程序退出。保留的数据在重装后可继续使用，自动清理保持关闭，须在设置中明确开启并保存。解压版移除前请先关闭自动清理并退出程序，再删除运行目录。
