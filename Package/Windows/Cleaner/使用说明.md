# Cleaner 使用方法

## 安装

从本仓库的 [Releases](https://github.com/Retracar/NareTools/releases) 下载安装包。需要 Windows 11 22H2 或更新版本、x64 系统，不需要另装 .NET。

选择安装位置，可安装至有写入权限的本地目录，包括 D 盘。桌面快捷方式和开始菜单入口分别设置。截图目录与应用安装位置相互独立。

首次使用按引导选择专用截图目录和保留期限，自动清理默认关闭。完成后再次启动直接进入应用。安装包尚未配置代码签名。

## 浏览截图

「最近截图」用于浏览、复制和分享。卡片下方「更多」提供打开、复制路径、重命名、文件夹定位、长期保留与删除。支持多选。列表、中图、大图直接切换，重新打开沿用上次选择。

重命名不覆盖同名文件；长期保留状态随新路径更新。分享使用 Windows 系统分享面板，可用目标取决于系统和已安装应用。

## 清理截图

「概览」可设置自动保留 7、14 或 30 天；「清理预览」可自定义几天、几周或几个月前的截图。时间依据文件最后修改时间，月按实际日历计算。

查看当前预览匹配项，再确认数量、大小、目录数和截止日期。搜索与状态筛选影响当前匹配范围。清理显示实际处理进度，可停止后续操作；已完成文件保留在回收站，并记录部分完成结果。

重要截图可设为「长期保留」，不会参与清理。删除与清理均移入 Windows 回收站，本工具不提供永久删除或清空回收站按钮。

## 目录和计划

设置中最多管理 32 个专用目录，只处理各目录第一层，不递归处理。移除管理目录不会删除文件。默认只纳入常见系统截图命名；关闭该选项后，同一目录下支持格式的普通图片也会纳入规则。

支持 PNG、JPG、JPEG、WEBP、BMP。跳过隐藏、系统及链接文件；不支持磁盘根目录、个人资料根目录和网络目录。任一目录失效时暂停本轮清理。

自动清理与保留期限独立，可设每 N 天／周／月、起始日期和时间，保存后生效。仅登录且插电时执行，不唤醒电脑，无需后台常驻。退出应用不会取消计划；关闭计划需在设置中关闭并保存。

从月末开始的月周期，在短月份的最后一天执行，之后仍按原起始日计算。错过多次会合并补做一次。

## 外观和数据

支持云母、亚克力、纯色和系统深浅主题；主题色可选 Nare 绿色、默认青色或壁纸取色。系统设置可能使透明材质回退。

配置、保护名单和最近 100 条清理记录保存在 `%LOCALAPPDATA%\NareTools-Cleaner`。截图不上传。

可从 Windows 回收站恢复文件。回收站仍占用磁盘空间，Windows 存储感知可能按系统设置自动清理回收站。

卸载会关闭计划并移除对应任务，保留截图、配置和历史。手动移动解压版前应先关闭计划，再从新位置启动并重新开启。不要同时用其他工具修改正在清理的目录。
